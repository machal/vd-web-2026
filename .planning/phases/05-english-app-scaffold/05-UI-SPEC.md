## Spacing Scale

VD utility classes map to an 8-point grid (multiples of 4). Use existing classes — do not invent pixel values in new markup.

| Token | Value | VD class examples | Usage |
|-------|-------|-------------------|-------|
| xs | 4px | `mb-025`, `p-025` | Tight inline gaps |
| sm | 8px | `mb-05`, `p-05` | Compact spacing, badge padding |
| md | 16px | `mb-1`, `p-1`, `mx-1` | Default element spacing |
| lg | 24px | `mb-15`, `pt-15`, `py-15` | Section padding, list item gaps |
| xl | 32px | `mb-2`, `py-2`, `pt-3` | Layout gaps, hero padding |
| 2xl | 48px | `mb-3`, `py-3`, `py-3-md` | Major section breaks |
| 3xl | 64px | `pt-3-md` (responsive) | Page-level top spacing |

Exceptions: **none** — use VD spacing utilities only.

## Typography

Four sizes only. Weights: **normal (400)** for body/labels; headings use VD `font-family: "foro extra bold"` (rendered as display weight — treat as single heading weight).

| Role | Size | Weight | Line Height | VD class |
|------|------|--------|-------------|----------|
| Body | 16px (1rem) | 400 | 1.5 (inherited) | default, `.f-5` |
| Label | 13px (0.8rem) | 400 | 1.4 | `.f-6`, `.f-sm` |
| Heading | 20px (1.25rem) | foro extra bold | 1.3 | `.h4`, `.f-4` |
| Display | 39px (2.441rem) | foro extra bold | 1.3 | `.h1`, `.lector__head-name` |

Article titles in stream: `.h4`. Page `<h1>` on `/martin` and 404: Display. Section `<h2>` on `/martin`: Heading.

## Color

60/30/10 split using existing VD CSS custom properties from `1-base.css`:

| Role | Value | CSS variable / class | Usage (60/30/10) |
|------|-------|----------------------|------------------|
| Dominant (60%) | `#fcfcf7` | `--vd-content-bg-color` | Main content surfaces, article body background |
| Secondary (30%) | `#e5e3df` / `rgb(228, 227, 223)` | `--vd-background-color` | Page backdrop, raised sections, `.bg-dark` bands on `/martin` |
| Accent (10%) | `#5fa316` links; `#eecf6d` highlights | `--vd-link-color`; `.bg-highlight`, `.button` | See reserved list below |
| Destructive | — | — | **None in Phase 5** — no destructive actions |

Accent reserved for:

- Primary CTA buttons (`.button` — hero “About Martin”, 404 nav buttons)
- Active primary nav item (`.nav__item--active .nav__item-in`)
- Inline text links (`a` default color)
- Article type badges (`.badge` — Blog / Guide labels)
- Highlight callout backgrounds (`.bg-highlight` on hero CTA area if used)
- **Not** for: body text, headings, footer legal links (standard link green only), metadata dates (`.text-color-lightest`)

Dark mode: inherit VD `@media (prefers-color-scheme: dark)` tokens — no EN-specific overrides.

## Visual Hierarchy

### Homepage (`/`)

1. **Focal point:** Hero block — name + tagline + one-line positioning (top of main)
2. **Secondary:** Primary CTA button to `/martin`
3. **Tertiary:** Unified article stream (newest first) — `ArticleListItem` list below hero divider

Layout: `page-head page-head--line` → hero in `.content-full` → `hr.hr--small.hr--spaced` → stream in `.content`. **No** CS homepage sidebar promos (podcast, courses, ebooks).

### `/martin`

1. **Focal point:** `lector__head` — name + portrait photo
2. **Secondary:** Performance consulting section (PageSpeed.ONE promotion)
3. **Tertiary:** Services accordion, client logos, LinkedIn CTA, publications/bio sections

Reuse CS page structure from `apps/vzhurudolu/src/pages/martin.astro` with EN copy. Section order (Claude's discretion within this contract):

1. Hero (name, photo, intro perex, LinkedIn link)
2. Web Performance / PageSpeed.ONE (prominent external links)
3. Services (accordion — training, audit, consulting)
4. Client logos (reuse `.bg-dark` band pattern)
5. Publications / bio (condensed — no CS ebook product grid; link to articles instead)
6. Contact (email, LinkedIn — omit Czech-only legal address block or shorten to email + LinkedIn only)

### Article detail (`/blog/{slug}`, `/guide/{slug}`)

1. **Focal point:** Article title (`ArticleHeader`)
2. **Secondary:** Article body content
3. **Tertiary:** `ArticleFooter` (no comments widget — EN-06)

### 404

1. **Focal point:** “Page not found” heading (centered)
2. **Secondary:** Two `.button` links — homepage + `/martin`

### Legal stubs (`/privacy`, `/cookies`)

1. **Focal point:** Page heading
2. **Secondary:** “Coming soon” body copy
