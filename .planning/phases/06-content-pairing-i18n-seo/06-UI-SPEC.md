# Phase 6 — UI Design Contract

> Language switch UI and paired-page visibility for cross-domain EN↔CS content. Reuses VD legacy CSS and shared Astro components. Generated by gsd-ui-researcher.

**Source decisions:** `06-CONTEXT.md`, `.planning/REQUIREMENTS.md` (I18N-03, VD-04), `05-UI-SPEC.md` (VD tokens), `.planning/research/ARCHITECTURE.md` (pairing schema).

## Component: LanguageSwitch

### Purpose

Let readers on paired content explicitly navigate to the counterpart page on the other domain. No dropdown, no auto-detect, no IP redirect (I18N-07).

### File & API

| Item | Value |
|------|-------|
| Path | `packages/shared/components/LanguageSwitch.astro` |
| Props | `currentLocale: 'cs' \| 'en'` (required), `alternateUrl: string` (required), `siteConfig?: SiteConfig` (optional — reserved for future copy tweaks; not used in Phase 6 markup) |

**Render rule:** If parent passes no `alternateUrl` (or `resolveAlternate()` returned `undefined`), **do not render** the component — no placeholder, no disabled state, no "coming soon" text. Unpaired pages must have zero language-switch markup in output.

### Labels (locked)

| Locale | Current (plain text) | Alternate (link) |
|--------|----------------------|------------------|
| `en` | **English** | **Česky** → `alternateUrl` |
| `cs` | **Česky** | **English** → `alternateUrl` |

- Native script names per I18N-03 — do not translate ("Czech", "Anglicky", flag emojis).
- Current language is **never** a link — `<span>` only.
- Alternate language is **always** a single `<a href="{alternateUrl}">` with absolute cross-origin URL.

### Markup contract

```html
<nav class="language-switch ta-c mb-1" aria-label="Language">
  <p class="language-switch__inner mb-0 f-6 text-color-lightest">
    <span class="language-switch__current" lang="{currentLocale}">{CurrentLabel}</span>
    <span class="language-switch__sep" aria-hidden="true"> · </span>
    <a
      class="language-switch__link"
      href="{alternateUrl}"
      hreflang="{alternateLocale}"
      lang="{alternateLocale}"
      rel="alternate"
    >{AlternateLabel}</a>
  </p>
</nav>
```

**Order:** current locale first, middle-dot separator, alternate link second — on both CS and EN sites.

**Separator:** middle dot ` · ` (same character as `page-subhead__date` em dash pattern family — metadata-tier punctuation).

### Styling (VD utility reuse)

| Element | Classes | Rationale |
|---------|---------|-----------|
| Wrapper `<nav>` | `language-switch ta-c mb-1` | Centered like `page-subhead`; 16px gap before article body |
| Inner `<p>` | `mb-0 f-6 text-color-lightest` | Label tier (13px / 0.8rem), muted metadata color |
| Current `<span>` | `language-switch__current` | Inherits muted color; no underline |
| Alternate `<a>` | `language-switch__link` | Inherits VD `a` color (`--vd-link-color`); underline on hover/focus per global link styles |

**No new CSS file required** if utilities suffice. Optional: add ≤10 lines to `page-subhead.css` (or shared static copy) only if executor needs `.language-switch { padding: 0 16px; }` for horizontal breathing room — prefer utilities first.

**Do not use:** `.button`, `.badge`, `.page-subhead` dark bar, icons, borders, or background fills. Switch is lightweight metadata — not a CTA button.

### Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Landmark | `<nav aria-label="Language">` |
| Current language | Plain text in `<span lang="…">` — not focusable |
| Decorative separator | `aria-hidden="true"` on ` · ` |
| Alternate link | Descriptive link text = language name ("Česky" / "English") — no "click here" |
| Focus | Inherit VD link focus ring from `1-base.css` |
| Screen reader context | `aria-label="Language"` on nav is sufficient; do not add visually hidden "Read in" prefix |

## Placement

### Article pages (blog, příručka/guide)

**Position:** Immediately **after** `ArticleHeader`, **before** `.content` wrapper — below title (`page-head`) and author/date meta (`page-subhead`), above article body.

```
<main>
  <ArticleHeader … />
  {LanguageSwitch — only when paired}
  <div class="content">
    <div class="article">…</div>
  </div>
  <ArticleFooter … />
</main>
```

**Applies to:**

| App | Routes |
|-----|--------|
| `apps/vzhurudolu` | `blog/[slug].astro`, `prirucka/[slug].astro` — 8 pilot pairs only |
| `apps/michalek-dev` | `blog/[slug].astro`, `guide/[slug].astro` — 8 pilot pairs + stubs |

Replace Phase 5 placeholder `<!-- language-switch: Phase 6 -->` **above** `ArticleHeader` with rendered `LanguageSwitch` **below** `ArticleHeader` per this contract.

**Vertical rhythm:** `mb-1` (16px) on switch; article `.content` keeps existing top spacing unchanged.

### `/martin` page pair

**Position:** Immediately **after** closing `</div>` of `.page-head.lector__head` (title + portrait + perex block), **before** first content section — equivalent vertical band to article pages (below hero title area, above main sections).

```
<div class="page-head lector__head">…</div>
{LanguageSwitch — only when paired}
<section class="content">…</section>
```

Same component, same classes, same labels — both `apps/vzhurudolu/src/pages/martin.astro` and `apps/michalek-dev/src/pages/martin.astro`.

### Pages without switch (explicit)

**No `LanguageSwitch` markup** on:

- Unpaired blog/příručka/guide articles
- Podcast, kurzy, e-books, homepage, listing pages, 404, legal stubs
- Any page where `resolveAlternate()` returns `undefined`

**Source:** `06-CONTEXT.md` Deferred; I18N-03 scope = 8 pairs + `/martin` only.

## Visual Hierarchy (paired article page)

1. **Focal point:** Article title (`ArticleHeader` `h1`) — unchanged
2. **Secondary:** Author + date meta (`page-subhead` dark band) — unchanged
3. **Tertiary:** Language switch (muted label row, centered)
4. **Body:** Article content (`.article`)

Language switch must **not** compete with title or author row. Muted `text-color-lightest` + `f-6` enforces tertiary hierarchy.

### `/martin` hierarchy

1. **Focal point:** Name + portrait (`lector__head`)
2. **Secondary:** Intro perex + social links
3. **Tertiary:** Language switch (same styling as articles)
4. **Body:** Performance/services sections

## Color

60/30/10 split unchanged from `05-UI-SPEC.md`:

| Role | Value | Usage in Phase 6 |
|------|-------|------------------|
| Dominant (60%) | `#fcfcf7` (`--vd-content-bg-color`) | Switch sits on content background |

| Accent (10%) | `#5fa316` (`--vd-link-color`) | **Alternate language link only** (hover/active underline) |

Accent reserved for (Phase 6 additions in **bold**):

- Primary nav active item (unchanged)
- Inline article links (unchanged)
- **Alternate language link in `LanguageSwitch`** (`language-switch__link`)
- **Not** for: current-language plain text, separator dot, switch wrapper, headings, author meta

Current language text uses `--vd-text-color-lightest` via `.text-color-lightest` — not accent green.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (alternate link, EN page) | **Česky** → Czech counterpart URL |
| Primary CTA (alternate link, CS page) | **English** → English counterpart URL |
| Current locale label (EN page) | **English** (plain text) |
| Current locale label (CS page) | **Česky** (plain text) |
| `aria-label` on `<nav>` | **Language** |
| Empty state (unpaired page) | **N/A — component not rendered; no user-facing message** |
| Error state (user-facing) | **N/A — no runtime error UI; build validator handles orphan pairs at CI time** |
| Destructive confirmation | **None** — no destructive actions |

**Cross-domain link behavior:** Standard navigation — full page load to other origin. No modal, no `target="_blank"`, no `noopener` needed for same-tab cross-origin navigation.

## Out of Scope (do not implement UI for)

- Full EN adapted article content (Phase 7)
- hreflang on unpaired CS-only content
- Auto language detection / geo redirect (I18N-07)
- Flag icons, globe icons, or dropdown locale picker
- Language switch in site header/footer/nav
- Translation UI, inline bilingual content, or "coming soon" EN stubs message in switch
